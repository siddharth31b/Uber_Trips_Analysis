# 🚖 Uber Trips Analysis

A comprehensive data analysis project on Uber pickup data using Python, Jupyter Notebook, and data visualization techniques. This project explores ride demand patterns, peak hours, and temporal trends in Uber pickups for New York City.

---

## 📌 Project Overview

The objective of this project is to analyze Uber trip datasets and uncover meaningful insights such as:

* Peak pickup hours and busiest time periods
* Daily and monthly ride trends
* Distribution of Uber pickups over time
* Patterns in customer demand and ride frequency
* Data-driven insights using visualizations and statistical analysis

This project demonstrates practical applications of **Data Analysis, Data Visualization, and Exploratory Data Analysis (EDA)** using real-world datasets.

## 🚀 How to Run the Project

### Clone the Repository

```bash
git clone https://github.com/siddharth31b/Uber_Trips_Analysis.git
```

### Navigate to Project Directory

```bash
cd Uber_Trips_Analysis
```

### Install Dependencies

```bash
pip install pandas numpy matplotlib seaborn scipy Scikit-learn
```

### Launch Jupyter Notebook

```bash
jupyter notebook
```

Open:

* `Uber_Pickups_NYC_July.ipynb`
* `Uber_Pickups_Analysis_Aug 14.ipynb`
